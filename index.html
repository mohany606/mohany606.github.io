In progress

Movie & TV recommendation system

Machine Learning course final project

View on GitHub ↗
Problem
Viewers face thousands of titles and little help finding ones that fit their taste.
Approach
A hybrid recommender on web-scraped title data. It combines text embeddings from titles and descriptions with TF-IDF features for tags and people, plus numeric metadata, into one weighted vector for similarity search.
In the repository
A Streamlit app named CineMatch with login or guest access, filters, similar-movie recommendations, favorites and watched lists, an offline rule-based chatbot, and a choice of models including a stacked XGBoost, KNN and logistic regression re-ranker.
Technologies
  • Python
  • Pandas
  • NumPy
  • Sentence-BERT
  • TF-IDF / SVD
  • Streamlit
  • XGBoost

Startup Destiny Predictor

Predicts whether a startup ends up Acquired or Closed, using over 48,000 startup funding histories. The README compares Logistic Regression, Decision Tree, Random Forest and LightGBM, uses stratified splits and balanced class weights for the roughly 8:1 imbalance, and selects a tuned LightGBM model inside a scikit-learn pipeline.
